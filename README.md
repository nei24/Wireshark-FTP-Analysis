# FTP Incident Analysis

## Objective

Analyze a network capture to identify an incident related to the FTP protocol using Wireshark.

## Tools Used

- Wireshark

- File PCAP

## Results

- FTP traffic was identified.

- Multiple authentication attempts were observed.

- A successful login was detected.

- Commands to list, download, and upload files were identified.

## Learning

I learned that FTP transmits information in plain text, which makes it possible to view usernames, passwords, and commands during a network sniff.
